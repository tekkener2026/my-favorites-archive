# V2RayN 使用说明

## 下载地址

[v2rayN Releases](https://github.com/2dust/v2rayN/releases)

## 各版本说明

- v2rayN: 基于 .NET Framework 4.6.2 的版本，仅支持 Windows。
- v2rayN-Core: 基于 .NET 6.0 的跨平台版本，支持 Windows、Linux、MacOS。
- v2rayN-Qt: 基于 Qt 的跨平台 GUI 客户端。

## 简介

v2rayN 是一个基于 V2Ray 内核的 Windows 客户端程序，支持 Vmess、Shadowsocks、Socks、HTTP、Trojan、VLESS 等协议。
